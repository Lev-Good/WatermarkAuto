# סימן מים אוטומטי ל־Windows

## הורדה והפעלה

מעמוד [המהדורה האחרונה](https://github.com/Lev-Good/WatermarkAuto/releases/latest) מורידים את המתקין `WatermarkAuto-Setup-Windows-x64-1.2.0.exe` ומפעילים אותו. לאחר ההתקנה פותחים את **WatermarkAuto** מתפריט התחל.

להפעלה ללא התקנה, מורידים את `WatermarkAuto-Windows-x64-1.2.0.zip`, מחלצים את כל הקבצים לתיקייה אחת ופותחים את `WatermarkAuto.exe`. שתי האפשרויות כוללות FFmpeg ואינן דורשות Python.

## שימוש

1. פותחים את **WatermarkAuto.exe** מהחבילה או את **Start Watermark.cmd** בהפעלה מקוד המקור.
2. בוחרים תיקיית קלט, תיקיית פלט וקובץ תמונה שישמש כסימן מים. PNG שקוף מאפשר להציג את הלוגו ללא רקע.
3. בוחרים את מיקום סימן המים ואת **איכות וגודל הפלט**, ולוחצים על **התחלת מעקב**.
4. מעתיקים תמונות או סרטונים לתיקיית הקלט. כשההעתקה מסתיימת, הקבצים נכנסים לעיבוד והפלט מופיע בתיקייה שנבחרה.

האפשרויות הן **גבוה**, **נמוך** ו־**דומה למקור**. האפשרות האחרונה משתמשת בגודל הקובץ המקורי כיעד משוער ויכולה לנסות עד שלוש הגדרות דחיסה. הגודל בפועל תלוי בפורמט ובתוכן. לשינוי האיכות במהלך מעקב יש לעצור את המעקב ולהפעיל אותו מחדש עם הבחירה החדשה.

המעקב כולל קבצים שכבר נמצאים ישירות בתיקיית הקלט. **עצירת מעקב** מאפשרת לעיבוד הנוכחי להסתיים ואז עוצרת את המעקב. לחיצה כפולה על שורת שגיאה ביומן מציגה את הפרטים. עצירה והפעלה מחדש מנסות שוב קבצים שנכשלו.

סרטונים נשמרים כ־MP4 עם אודיו, אם היה במקור. תמונות נשמרות בפורמט המקורי. קובצי המקור נשארים בתיקיית הקלט. שם הפלט כולל סיומת מזהה קצרה, כך שקובץ שכבר עובד עם אותו סימן ומיקום ידולג כל עוד הפלט קיים. סימן מים גדול מוקטן לפי הצורך כדי להיכנס לרבע מרוחב ורבע מגובה התמונה לכל היותר.

- תמונות: PNG, JPEG, WebP, BMP, TIFF.
- סרטונים: MP4, MOV, MKV, AVI, WebM, M4V, WMV, MTS, M2TS, MPG, MPEG.

- **עצירת עיבוד נוכחי** מבטלת את הקובץ שבעיבוד וממשיכה במעקב. כדי לנסות שוב את אותו קובץ, עוצרים את המעקב ומפעילים אותו מחדש.
- **המשך מעקב ברקע בסגירת החלון** משאיר את המעקב פעיל באזור ההודעות של Windows. לוחצים על סמל התוכנה כדי לפתוח את החלון, או בוחרים **יציאה** בתפריט הסמל כדי לסגור את התוכנה.
- **התראת Windows בסיום עיבוד** שולחת התראת מערכת לאחר שמירת קובץ בהצלחה, גם כשהחלון מוסתר. הצגת ההתראה כפופה להגדרות Windows.

## הפעלה מקוד המקור

נדרש Python 3.11 ומעלה עם Tkinter. אם אין עותק מקומי של FFmpeg, ההפעלה הראשונה תתקין אותו בתיקיית הפרויקט באמצעות [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg). אפשר גם להניח בתיקייה קובץ `ffmpeg.exe` מגרסה 7.1 ומעלה עם libx264. עיבוד המדיה מתבצע מקומית באמצעות [FFmpeg](https://github.com/FFmpeg/FFmpeg) והמסנן [overlay](https://ffmpeg.org/ffmpeg-filters.html#overlay).

בהפעלה הראשונה `Start Watermark.cmd` מתקין לפי הצורך גם את הרכיבים למעקב אחר תיקיית הקלט ולאזור ההודעות של Windows, כמפורט ב־`requirements.txt`.
